개인정보 처리방침

AST - AI Subtitle Translator는 Udemy, YouTube, TED, NVIDIA Academy, Vimeo, Coursera, LinkedIn Learning, O'Reilly, NVIDIA On-Demand, DeepLearning.AI, edX의 자막을 사용자가 선택한 번역 서비스로 번역해 표시하는 Chrome 확장 프로그램입니다. 개발자는 별도의 서버를 운영하지 않으며, 광고·추적·분석 목적으로 사용자 데이터를 수집하지 않습니다.

01

처리하는 데이터

  • Udemy, YouTube, TED, NVIDIA Academy, Vimeo, Coursera, LinkedIn Learning, O'Reilly, NVIDIA On-Demand, DeepLearning.AI, edX의 자막 텍스트와 자막 구간의 시간 정보
  • 현재 영상·강의를 식별하는 URL, 영상 ID, 강좌 ID, 강의 ID 및 자막 언어 정보
  • 범용 동영상 플레이어(테크니컬 프리뷰) 지원 목록에 사용자가 추가한 사이트: 그 사이트 주소(호스트 이름), 그 사이트 페이지의 동영상 요소 정보와 동영상의 자막 텍스트·시간 정보
  • 사용자가 입력한 번역 제공업체의 API 키, 엔드포인트, 모델, 번역·자막 설정
  • 번역 결과 캐시와 사용자가 직접 생성하는 암호화 설정 백업 파일
02

이용 목적

이 데이터는 자막 조회, 번역 요청, 번역 결과 표시, 사용자 설정 유지, 설정 백업·복구 기능을 제공하는 데만 사용됩니다. 개인 맞춤 광고, 사용자 프로파일링, 데이터 판매에 사용하지 않습니다.

03

저장과 보유

  • 설정, 번역 캐시, API 키는 사용자의 브라우저 chrome.storage.local에 저장됩니다.
  • API 키는 제공업체별 AES-GCM 암호문으로 저장되며 일반 설정에는 평문으로 남기지 않습니다. 복호화에 필요한 조각도 같은 브라우저 프로필에 있으므로 OS 보안 저장소나 사용자의 마스터 비밀번호로 보호하는 비밀 저장소와 동일한 보호 수준은 아닙니다.
  • 저장소는 신뢰된 확장 프로그램 컨텍스트로 제한되며 콘텐츠 스크립트는 API 키 또는 복호화 조각에 직접 접근하지 않습니다.
  • 설정 백업은 사용자가 입력한 비밀번호로 AES-GCM 암호화하며, 비밀번호는 저장하지 않습니다.
  • 번역 캐시는 설정에서 삭제할 수 있고, 전체 설정은 초기화할 수 있습니다. 확장 프로그램을 제거하면 Chrome이 해당 로컬 저장소를 삭제합니다. 사용자가 내려받은 .astbackup 파일은 사용자가 직접 삭제해야 합니다.
04

외부 전송

  • 자막 텍스트와 번역 설정은 사용자가 선택한 Google Translate, DeepL, OpenAI, Anthropic, Google AI, OpenRouter, NVIDIA NIM 또는 Custom LLM 엔드포인트로 전송될 수 있습니다.
  • API 키는 인증이 필요한 요청에서 선택한 제공업체로 직접 전송됩니다. 개발자 서버로 전송되지 않습니다.
  • 지원 사이트의 자막을 조회하기 위해 영상·강의 식별자와 사용자의 로그인 쿠키가 포함된 요청이 전송될 수 있습니다. 확장 프로그램은 쿠키 값을 별도로 저장하지 않습니다.
  • 기본 또는 사용자 지정 웹폰트를 사용하면 Google Fonts, jsDelivr 또는 사용자가 CSS에 지정한 폰트 서버로 폰트 요청이 전송될 수 있습니다.
  • 각 외부 서비스의 데이터 처리는 해당 서비스의 개인정보 처리방침과 이용약관을 따릅니다.
05

권한

  • storage: 설정, 암호화된 API 키와 번역 캐시를 로컬에 저장합니다.
  • scripting: YouTube 페이지 시작 시 플레이어의 자막 응답을 수집합니다. 쿠키·인증 헤더·서명 URL을 제외한 자막 텍스트와 언어·시간 정보만 확장 프로그램에 전달합니다.
  • 호스트 권한: 모든 사이트(<all_urls>) 접근 권한을 사이트마다 나열하지 않고 한 번에 요청하며, 실제 동작 범위는 코드에서 제한합니다. 자막 스크립트는 Udemy·YouTube·TED·NVIDIA Academy·Vimeo·Coursera·LinkedIn Learning·O'Reilly·NVIDIA On-Demand·DeepLearning.AI·edX 페이지에만 주입하고, 네트워크 요청은 이 사이트들의 자막 조회와 사용자가 선택한 번역 제공업체(공식 HTTPS 주소 또는 사용자가 입력한 Custom LLM 주소)로만 보냅니다. 다른 사이트의 페이지 내용은 읽거나 전송하지 않습니다. 단, 사용자가 툴바 팝업에서 범용 동영상 플레이어(테크니컬 프리뷰) 지원 목록에 추가한 사이트에서는 동영상 감지용 작은 스크립트가 들어가고, 자막이 있는 동영상이 있는 프레임에만 자막 스크립트를 주입해 그 동영상의 자막 파일을 요청합니다. 확장 프로그램이 직접 자막 파일을 요청할 때는 쿠키를 보내지 않으며 사설망·로컬 주소는 요청하지 않습니다. 목록에 없는 사이트에서는 동작하지 않습니다.
06

Google API Limited Use

Google API로부터 수신한 정보의 사용은 Limited Use 요구사항을 포함한 Chrome Web Store User Data Policy를 준수합니다.

07

보안

모든 원격 제공업체 요청은 HTTPS를 사용합니다. Custom LLM은 사용자의 컴퓨터에서 실행하는 로컬 LLM과 사용자 지정 서버를 함께 지원합니다. 로컬 LLM은 localhost, 127.0.0.1, 사설망 주소(RFC 1918: 10.x.x.x, 172.16~31.x.x, 192.168.x.x), .local 이름의 HTTP 엔드포인트를 사용할 수 있고(HTTP는 암호화되지 않으므로 신뢰할 수 있는 내부망에서만 사용하세요), 그 밖의 사용자 지정 서버는 HTTPS와 사용자의 실행 시 도메인 접근 승인이 필요합니다. 공식 제공업체의 Base URL은 해당 제공업체의 공식 HTTPS 오리진으로 제한하고 리디렉션 응답을 자동으로 추적하지 않습니다.
