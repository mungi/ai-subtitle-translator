No subscription. Just your own API key.

Sign up directly with an AI provider, enter your key, and pay that provider only for the tokens you actually use.

A monthly translation plan charges the same whether you watch one video or fifty. With AST you create an API key at OpenAI, Anthropic, Google AI, or OpenRouter, and each request is billed by that provider at its own token price, with no markup and nothing in between.

Subtitles are short, clear text, so small fast models translate them well. That keeps the bill tiny: 100,000 subtitle sentences cost about $1.60 to $5.80 with these models, and nothing at all on Gemini's free tier (within its daily limits) or with a model on your own computer.

Run a model on your laptop, or connect any LLM service

Custom LLM works with any OpenAI-compatible chat/completions API, so you are never locked into one provider.

On your own laptop

Run an open model with a tool such as LM Studio or Ollama and translate at no cost. localhost and 127.0.0.1 can use plain HTTP, and subtitle text stays on your computer.

Any LLM service

Connect any provider or self-hosted server that offers an OpenAI-compatible API over HTTPS. Enter its Base URL, API key, and model name, and AST does the rest.

Straight to your server

Subtitle text, and your API key if you set one, go directly from your browser to the server you chose. Nothing passes through a developer server.

A better way to follow subtitles

Right on the video

Show translated subtitles, source subtitles, or both together over Udemy, YouTube, TED, NVIDIA Academy, and Vimeo players. Use the AST menu to turn subtitles on or off and choose a source subtitle language or translation style.

Translation that understands the full video

When you choose an AI provider, the LLM considers surrounding subtitles and the video flow to create natural, connected translations.

In the voice you want

Use a custom prompt to set the translation tone and wording, from an instructional or friendly voice to the style of technical documentation or the lively delivery of a top instructor.

AST icon status

Use the icon color to see the translation state at a glance. It gently pulses in its current color while subtitle or translation requests are being prepared.

  • White · DefaultAST is off or original subtitles are shown
  • Blue · ActiveThe default active state while translated subtitles are prepared or shown
  • Yellow · TemporaryTemporary translation is shown while final LLM translation is pending
  • Green · Current cue readyFinal translation is ready for the currently playing cue
  • Purple · CompleteFinal translation is complete for the full subtitle track
  • Pink · FallbackGoogle Translate fallback is in use, such as after a quota limit is reached
  • Orange · YouTube auto-translationYouTube's auto-translated subtitles are shown instead of a translation

We use only the data needed for translation

We do not operate developer servers for advertising, tracking, or analytics.

Subtitle text and translation settings may be sent to the translation provider you choose. API keys, settings, and translation cache are stored in your browser and are not sent to developer servers.

API keys are encrypted at rest and content scripts cannot read them directly. The information needed for automatic decryption remains in the same browser profile, so this is not equivalent to secure OS storage.
