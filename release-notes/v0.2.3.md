## What's Changed

This release adds **Vimeo live event** subtitles and **YouTube Shorts** support.

### Highlights
- **Vimeo live events**: AST works on live events (`vimeo.com/event/...`), including ones embedded in other sites. New lines are read as soon as Vimeo publishes them. Translation runs forward from the playback position, and seeking back to an earlier part of the event translates that part.
- **YouTube Shorts**: the AST button appears on Shorts, and subtitles are collected and shown there too.

### Also new
- Short subtitle lines stay on screen for at least 2 seconds, unless the next line starts.
- When the player or frame is too small for the AST menu, the menu scrolls instead of being cut off.
- Hebrew is available as a target language. The target language list shows each language's code.
- Choosing a translation style while YouTube-provided subtitles are shown translates with that style.
- OpenAI and OpenRouter use low reasoning effort by default, for less literal translations. If a model rejects the reasoning option, AST retries without it.
