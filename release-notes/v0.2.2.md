## What's Changed

This release adds **6 more supported sites** and a **generic video player (Technical Preview)** for sites that are not on the list.

### Highlights
- **New supported sites**: Coursera, LinkedIn Learning, O'Reilly, NVIDIA On-Demand, DeepLearning.AI, and edX.
- **Generic video player (Technical Preview)**: add any site from the toolbar popup and translate the subtitles of standard HTML5 videos (`<track>`, HLS, player text tracks; VTT, SRT, TTML).
- **Custom LLM on your local network**: plain HTTP is now allowed for private network addresses (RFC 1918: `10.x.x.x`, `172.16–31.x.x`, `192.168.x.x`) and `.local` names, in addition to `localhost` and `127.0.0.1`. Other external servers still require HTTPS.

### Also new
- Subtitle font size −/+ buttons in the subtitle display menu (original, translation, or both for dual subtitles).
- Custom LLM: reasoning effort, JSON response mode, extra request headers, and context size detection in the connection test.
- Popup and Settings cleanup: supported sites are shown in a sorted grid, NVIDIA Academy and NVIDIA On-Demand are grouped, and the popup manages only unsupported sites.
- YouTube: phrase regrouping is skipped for human-made captions by default.

### Fixes
- More stable YouTube caption capture and clearer messages when captions are missing.
- Fixed clipped video and tiny subtitles in edX fullscreen.
