# AST - AI Subtitle Translator
AI를 활용해 Udemy, YouTube 등 주요 온라인 강의·영상 사이트의 교육 콘텐츠(온라인 강의, 강연, 튜토리얼 영상) 자막을 원하는 언어로 자연스럽게 번역합니다. 언어의 장벽 없이 학습할 수 있어 자막 접근성도 높아집니다.
지원 사이트 전체 목록은 소개 웹사이트에서 확인하세요: https://mungi.github.io/ai-subtitle-translator/

# 주요 특징
  - 내 API 키를 직접 사용합니다. OpenAI, Anthropic, Google AI 등 원하는 제공업체의 API 키를 입력하거나, Custom LLM으로 OpenAI 호환 서버·로컬 LLM(Ollama, LM Studio 등)을 연결해 원하는 모델로 번역할 수 있습니다.
  - Google 번역으로 자막을 빠르게 번역하거나, LLM을 활용해 문맥을 고려한 자연스러운 번역을 제공합니다.
  - 원문과 번역을 함께 보여 주는 이중 자막으로 시청할 수 있어, 외국어 교육 콘텐츠도 모국어 자막으로 쉽게 이해하며 원문 표현까지 함께 익힐 수 있습니다.
  - 범용 동영상 플레이어(테크니컬 프리뷰): 위 목록에 없는 사이트도 툴바 팝업에서 지원 목록에 추가하면, 자막(트랙)이 있는 일반 HTML5 동영상의 자막을 번역할 수 있습니다.
  - 프롬프트를 활용하여 번역 스타일을 지정할 수 있습니다.
  - 자막 표시 스타일을 다양하게 직접 변경할 수 있습니다.
  - 다양한 상용 AI API와 OpenAI 호환 API·로컬 서버를 포함한 여러 LLM 제공업체를 지원합니다. 설정에서 제공업체·모델·API 키를 선택할 수 있으며, 전체 지원 목록은 Chrome Web Store의 설정 화면 스크린샷에서 확인하세요.

# 주의 사항
  - 일부 번역 제공업체는 API 키가 필요합니다. Custom LLM의 API 키는 선택 사항입니다.
  - Google AI API 키를 발급해 무료 등급의 Gemini 3.1 Flash Lite를 연결하면 응답이 빠른 AI 번역을 시작할 수 있습니다. (권장)
  - 최근 Google AI 무료 API는 사용량이 많은 시간대에 오류가 잦습니다. 안정적인 번역이 필요하면 OpenAI gpt-6-luna나 Anthropic claude-haiku-5-5 같은 유료 API를 권장합니다. (문장 10,000개당 약 $0.2~$0.5)
  - 무료 사용량과 제한 및 발생 비용은 각 LLM API 제공업체의 정책을 확인해 주세요.

# 주요 기능
  - 주요 지원 사이트의 영상 AI 자막 번역
  - 원문 흐름을 고려한 AI 문맥 번역
  - Google 번역을 이용한 빠른 번역 기본 제공
  - LLM 번역이 준비되는 동안 임시 번역을 먼저 표시
  - 영상에서 제공하는 자막 언어를 번역 소스 언어로 선택 가능 (기본값: 영어)
  - 자막 표시, 위치 이동, 폭 조절 지원
  - 이중 자막·원문 자막·번역 자막 선택 가능 (기본값: 이중 자막)
  - YouTube 사람 자막·자동 번역 우선 사용 (옵션)
  - 원문·번역 자막 글꼴을 따로 설정하고 번역 자막 위치(상단·하단) 선택
  - 자동 생성 자막을 구문 단위로 재구성해 읽기 쉽게 표시
  - 플레이어 메뉴에 번역 상태와 진행률 표시
  - 자막 글꼴, 색상, 그림자, 외곽선, 배경색, 투명도 변경 지원
  - 다양한 번역 스타일 지원: Natural, Lecture, Technical, Custom 1(스타 강사), Custom 2
  - 긴 영상 자막의 분할·병렬 번역 및 번역 캐시 지원
  - API 키를 포함한 설정의 비밀번호 기반 암호화 백업·복구 제공
  - AI 번역 실패 시 원문 자막을 유지하고, 가능한 경우 Google 번역으로 대체

# 사용 방법
  - 설치 시 Google 번역이 기본 제공됩니다.
  - 자막이 제공되는 지원 영상에서는 번역이 자동으로 시작됩니다. 동영상 툴바의 `AST` 메뉴에서 `AI 자막 번역`을 켜거나 끌 수 있습니다.

  ## 간단 설정 - 권장
  1. 확장 프로그램을 설치하고 설정 페이지에서 간단 설정 하단의 `API 키 발급하기` 링크를 클릭하여 Google AI API 키를 발급받습니다.
  2. 발급받은 무료 API 키를 설정의 `Google AI API 키` 항목에 넣고 `API 키 확인` 버튼을 누릅니다. 확인에 성공하면 Google AI 제공업체와 `gemini-3.1-flash-lite` 모델이 자동으로 설정됩니다.

  처음 사용하는 모델 선택 가이드는 소개 웹사이트의 [LLM 선택 가이드](https://mungi.github.io/ai-subtitle-translator/#llm-selection-guide)에서 확인하세요.

  ## 고급 설정
  - API 키가 필요한 제공업체를 사용할 경우, 해당 제공업체에서 발급한 API 키를 입력한 후 `연결 테스트` 버튼을 누릅니다.
  - 필요에 따라 번역 스타일과 자막 표시 스타일을 조절할 수 있습니다.
  - API 키를 포함한 모든 설정값을 백업할 수 있습니다. 백업 파일은 AES-256-GCM으로 암호화되며, 복구 시에는 백업할 때 입력한 암호가 필요합니다.
  - DeepL API 키가 있는 경우 빠른 번역에 DeepL을 사용할 수 있습니다. (Free·Pro 요금제 선택)

# 권한 안내
  - 사이트 접근 권한(모든 사이트)
    - v0.2.0부터 확장 프로그램이 접근하는 사이트를 하나하나 나열하던 방식(24개)을 "모든 사이트" 하나로 바꿨습니다.
    - 필요한 이유
      - 지원 동영상 사이트를 계속 늘려 갈 계획입니다. 새 사이트를 지원할 때마다 권한이 바뀌어 다시 승인해야 하는 번거로움을 없애기 위해 권한을 한 번에 받습니다.
      - Custom LLM: 사용자가 직접 운영하거나 선택한 OpenAI 호환 서버는 어떤 주소에든 있을 수 있습니다. 이전에는 주소를 바꿀 때마다 권한을 따로 요청해야 했습니다.
      - 여러 번역 제공업체와 동영상 사이트의 자막 서버 주소를 사용자가 고른 설정에 따라 바로 쓸 수 있습니다.
      - Chrome의 사이트 접근 목록에 주소가 길게 나열되어 오히려 알아보기 어려웠던 문제를 정리했습니다.
      - 범용 동영상 플레이어(테크니컬 프리뷰): 사용자가 툴바 팝업에서 범용 플레이어 지원 목록에 추가한 사이트에만 동영상 감지용 작은 스크립트를 등록하고, 자막이 있는 동영상이 있는 프레임에만 자막 스크립트를 주입해 그 동영상 자막을 번역합니다. 사이트가 사용자의 선택으로 정해지므로 사이트별 권한을 미리 나열할 수 없습니다.
    - 실제 사용 범위
      - 자막 표시 스크립트는 지원하는 동영상 사이트에만 들어갑니다. 다른 웹사이트의 내용은 읽거나 바꾸지 않습니다.
      - 네트워크 요청은 지원 사이트의 자막 조회와 사용자가 선택한 번역 제공업체로만 보냅니다. 요청 대상은 코드에서 다시 확인합니다.
  - storage: 설정, 암호화된 API 키, 번역 캐시를 브라우저에 저장합니다.
  - scripting: 지원 동영상 사이트에서 자막을 가져오는 스크립트를 실행합니다.

# 개인정보 및 데이터 처리
- 개인정보 처리방침: https://mungi.github.io/ai-subtitle-translator/privacy.html
- 자막 텍스트는 사용자가 선택한 번역 제공업체로 전송될 수 있습니다.
- API 키와 설정, 번역 캐시는 사용자의 브라우저에만 저장됩니다.
- API 키는 브라우저 저장소에 제공업체별 암호문으로 저장되며 설정 데이터에는 평문 API 키를 남기지 않습니다.
- 저장소 접근은 신뢰된 확장 프로그램 컨텍스트로 제한하며 콘텐츠 스크립트에는 API 키를 전달하지 않습니다.
- 이 확장은 자체 서버나 외부 데이터베이스에 API 키를 저장하지 않습니다.
- 번역 요청 시 API 키는 인증을 위해 선택한 제공업체에 직접 전송됩니다.
- 호스팅 제공업체는 공식 HTTPS 오리진만 허용합니다. Custom LLM은 `localhost`/`127.0.0.1`, 사설망 주소(RFC 1918), `.local` 이름의 HTTP 또는 HTTPS와, 사용자가 입력한 사용자 지정 HTTPS 오리진을 사용할 수 있으며 리디렉션 응답을 자동으로 추적하지 않습니다.
- 호스트 권한은 모든 사이트로 한 번에 요청하지만, 자막 스크립트는 지원 동영상 사이트에만 주입하고 네트워크 요청은 지원 사이트의 자막 조회와 사용자가 선택한 번역 제공업체로만 보냅니다.
