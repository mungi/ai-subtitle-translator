# AST - AI Subtitle Translator

次のウェブサイトの動画字幕を、LLM ベースの AI で希望する言語へ自然に翻訳します。
  - Udemy: https://www.udemy.com/
  - NVIDIA Academy: https://www.nvidia.com/en-us/training/academy/
  - YouTube: https://www.youtube.com/
  - Vimeo: https://vimeo.com/
  - TED: https://www.ted.com/

# 主な特徴
  - Google 翻訳で字幕をすばやく翻訳するか、LLM を接続して文脈を考慮した自然な翻訳を利用できます。
  - 原文と翻訳を同時に表示する二重字幕で視聴できます。
  - プロンプトを使って翻訳スタイルを指定できます。
  - 字幕の表示スタイルを自由にカスタマイズできます。
  - 商用 AI API、OpenAI 互換 API、ローカルサーバーを含む複数の LLM プロバイダーに対応しています。設定でプロバイダー、モデル、API キーを選択でき、対応プロバイダーの一覧は Chrome ウェブストアに掲載された設定画面のスクリーンショットで確認できます。

# 注意事項
  - 一部の翻訳プロバイダーには API キーが必要です。Custom LLM の API キーは任意です。
  - Google AI API キーを作成して無料枠の Gemini 3.1 Flash Lite を接続すると、応答の速い AI 翻訳を開始できます。（推奨）
  - 最近、Google AI の無料 API は利用が集中する時間帯にエラーが多発しています。安定した翻訳が必要な場合は、OpenAI gpt-6-luna や Anthropic claude-haiku-5-5 などの有料 API をおすすめします。（10,000 文あたり約 $0.2〜$0.5）
  - 無料利用枠、制限、発生する料金は、各 LLM API プロバイダーのポリシーを確認してください。

# 主な機能
  - Udemy、NVIDIA Academy、YouTube、TED、Vimeo 動画の字幕翻訳
  - 原文字幕の流れを考慮した AI 文脈翻訳
  - Google 翻訳による高速翻訳を標準搭載
  - LLM 翻訳の準備中は高速翻訳を先に表示
  - 動画が提供する字幕言語を翻訳元言語として選択可能（既定値: 英語）
  - 字幕表示、位置調整、幅調整に対応
  - 二重字幕・原文字幕・翻訳字幕を選択可能（既定値: 二重字幕）
  - YouTube の人による字幕・自動翻訳を優先使用（オプション）
  - 原文字幕と翻訳字幕のフォントを個別に設定し、翻訳字幕の位置（上・下）を選択可能
  - 自動生成字幕をフレーズ単位に再構成して読みやすく表示
  - プレイヤーメニューに翻訳状況と進捗を表示
  - 字幕のフォント、色、影、アウトライン、背景色、不透明度を変更可能
  - 翻訳スタイル: Natural、Lecture、Technical、Custom 1（スター講師）、Custom 2
  - 長い動画の字幕を分割・並列翻訳し、翻訳キャッシュを利用可能
  - API キーを含む設定のパスワード暗号化バックアップ／復元
  - AI 翻訳に失敗した場合は元字幕を維持し、可能な場合は Google 翻訳に切り替え

# 使い方
  - インストール時には Google 翻訳が標準で利用できます。
  - 字幕がある対応動画では翻訳が自動的に始まります。動画ツールバーの `AST` メニューから `AI 字幕翻訳` のオン・オフを切り替えられます。

  ## かんたん設定 — 推奨
  1. 拡張機能をインストールし、設定ページのかんたん設定下部にある `API キーを取得` リンクをクリックして Google AI API キーを作成します。
  2. 作成した無料 API キーを設定の `Google AI API キー` に入力し、`API キーを確認` をクリックします。確認に成功すると、Google AI プロバイダーと `gemini-3.1-flash-lite` モデルが自動設定されます。

  初めて使う場合のモデル選択ガイドは、紹介ウェブサイトの [LLM 選択ガイド](https://mungi.github.io/ai-subtitle-translator/#llm-selection-guide)で確認してください。

  ## 詳細設定
  - API キーが必要なプロバイダーを使う場合は、そのプロバイダーで発行した API キーを入力してから `接続テスト` をクリックします。
  - 必要に応じて翻訳スタイルと字幕表示スタイルを調整できます。
  - API キーを含むすべての設定をバックアップできます。バックアップファイルは AES-256-GCM で暗号化され、復元にはバックアップ時に入力したパスワードが必要です。
  - DeepL API キーがある場合は、高速翻訳に DeepL を使用できます。（Free・Pro プラン選択可）

# 権限について
  - サイトへのアクセス権限（すべてのサイト）
    - v0.2.0 から、拡張機能がアクセスするサイトを個別に列挙する方式（24 件）を「すべてのサイト」1 つにまとめました。
    - 必要な理由
      - 対応動画サイトを今後も増やしていく予定です。サイトを追加するたびに権限が変わり、再承認が必要になる手間をなくすため、権限を一度にまとめて取得します。
      - Custom LLM: ユーザーが運用または選択した OpenAI 互換サーバーは、どのアドレスにも置かれる可能性があります。以前はアドレスを変えるたびに権限を個別に要求する必要がありました。
      - 動画サイトの字幕サーバーや、ユーザーが選んだ翻訳プロバイダーのエンドポイントをすぐに利用できます。
      - Chrome のサイトアクセス一覧にアドレスが長く並び、かえって分かりにくかった問題を整理しました。
    - 実際の利用範囲
      - 字幕表示スクリプトは対応動画サイト（Udemy、NVIDIA Academy、YouTube、TED、Vimeo）にのみ挿入します。その他のウェブサイトの内容を読み取ったり変更したりしません。
      - ネットワーク要求は、対応サイトでの字幕取得とユーザーが選択した翻訳プロバイダーにのみ送信します。要求先はコードで再確認します。
  - storage: 設定、暗号化された API キー、翻訳キャッシュをブラウザに保存します。
  - scripting: 対応動画サイトで字幕を取得するスクリプトを実行します。

# プライバシーとデータの取り扱い
- プライバシーポリシー: https://mungi.github.io/ai-subtitle-translator/privacy-ja.html
- 字幕テキストは、ユーザーが選択した翻訳プロバイダーに送信される場合があります。
- API キー、設定、翻訳キャッシュはユーザーのブラウザー内にのみ保存されます。
- API キーはブラウザーの保存領域にプロバイダー別の暗号文として保存され、設定データに平文の API キーは残りません。
- 保存領域へのアクセスは信頼された拡張機能コンテキストに制限され、API キーはコンテンツスクリプトに公開されません。
- この拡張機能は、独自サーバーや外部データベースに API キーを保存しません。
- API キーは認証のために必要な場合、選択したプロバイダーへ直接送信されます。
- ホスト型プロバイダーは公式 HTTPS オリジンのみに制限されます。Custom LLM は `localhost`／`127.0.0.1` の HTTP または HTTPS と、ユーザーが入力したカスタム HTTPS オリジンを使用でき、リダイレクト応答を自動追跡しません。
- ホスト権限はすべてのサイトに対して一度に要求しますが、字幕スクリプトは対応動画サイトにのみ挿入し、ネットワーク要求は対応サイトでの字幕取得とユーザーが選択した翻訳プロバイダーにのみ送信します。
